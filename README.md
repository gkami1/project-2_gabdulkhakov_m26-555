# project-2_gabdulkhakov_m26-555

Консольное приложение на Python, имитирующее работу с базой данных.
Проект выполнен в рамках домашней работы по основам Python.

## Возможности

- Создание таблиц с типизированными столбцами (`int`, `str`, `bool`).
- Удаление таблиц.
- Просмотр списка таблиц.
- Сохранение метаданных в JSON-файл (`db_meta.json`) — данные не теряются между запусками.
- Автоматическое добавление столбца `ID:int` в начало каждой таблицы.

## Требования

- Python 3.12+
- [Poetry](https://python-poetry.org/) 1.2+
- Linux или macOS

Клонируйте репозиторий и установите зависимости:

## Запуск

Пакет предоставляет две команды — `project` и `database`. Они запускают одну и ту же программу.

Через Poetry:

```bash

```

Через Makefile:

```bash
make project
```

После установки пакета в систему (`make package-install`) команды доступны напрямую:

```bash

```

## Управление таблицами

### Команды

| Команда | Описание |
|---|---|
| `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` | Создать таблицу |
| `list_tables` | Показать список всех таблиц |
| `drop_table <имя_таблицы>` | Удалить таблицу |
| `help` | Показать справку |
| `exit` | Выйти из программы |

Поддерживаемые типы данных: `int`, `str`, `bool`.

Столбец `ID:int` добавляется автоматически в начало каждой таблицы и не задаётся пользователем.

### Пример использования

```text
***База данных***

***Процесс работы с таблицей***
Функции:
<command> create_table <имя_таблицы> <столбец1:тип> .. - создать таблицу
<command> list_tables - показать список всех таблиц
<command> drop_table <имя_таблицы> - удалить таблицу

Общие команды:
<command> exit - выход из программы
<command> help - справочная информация

>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.

>>>Введите команду: drop_table products
Ошибка: Таблица "products" не существует.

>>>Введите команду: exit
```

### Обработка ошибок

- Неизвестная команда: `Функции <имя> нет. Попробуйте снова.`
- Некорректное значение аргумента: `Некорректное значение: <значение>. Попробуйте снова.`
- Пустой ввод — приглашение повторяется.

## Хранение данных

Все метаданные таблиц хранятся в файле `db_meta.json` в директории, из которой запущена программа. Пример содержимого:

```json
{
  "users": {
    "columns": [
      ["ID", "int"],
      ["name", "str"],
      ["age", "int"],
      ["is_active", "bool"]
    ]
  }
}
```

## Разработка

### Makefile

| Команда | Действие |
|---|---|
| `make install` | Установить зависимости (`poetry install`) |
| `make project` | Запустить программу (`poetry run project`) |
| `make build` | Собрать пакет (`poetry build`) |
| `make publish` | Отладочная публикация (`poetry publish --dry-run`) |
| `make package-install` | Установить собранный пакет из `dist/*.whl` |
| `make lint` | Проверить код линтером (`poetry run ruff check .`) |

### Линтер

Проект использует [Ruff](https://docs.astral.sh/ruff/) для статического анализа и форматирования кода.

```bash
poetry run ruff check .
poetry run ruff check . --fix
poetry run ruff format .
```

## Технологии

- **Poetry** — управление зависимостями и сборка пакета.
- **Ruff** — линтер и форматтер.
- **prompt** — ввод данных от пользователя.
- **shlex** — безопасный разбор командной строки.
- **json** — хранение метаданных.
