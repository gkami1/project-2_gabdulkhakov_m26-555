# project-2_gabdulkhakov_m26-555

Консольное приложение на Python, имитирующее работу с базой данных.
Проект выполнен в рамках домашней работы по основам Python.

## Возможности

- Создание таблиц с типизированными столбцами (`int`, `str`, `bool`).
- Удаление таблиц и просмотр их списка.
- Автоматическое добавление столбца `ID:int` в начало каждой таблицы.
- CRUD-операции с записями: `insert`, `select`, `update`, `delete`.
- Фильтрация записей по условию `where`, вывод в виде таблицы (`prettytable`).
- Сохранение метаданных в `db_meta.json`, а данных каждой таблицы — в `data/<таблица>.json`.

## Требования

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) 0.5+

## Управление таблицами

### Команды

| Команда | Описание |
|---|---|
| `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` | Создать таблицу |
| `list_tables` | Показать список всех таблиц |
| `drop_table <имя_таблицы>` | Удалить таблицу |
| `help` | Показать справку |
| `exit` | Выйти из программы |

Поддерживаемые типы данных: `int`, `str`, `bool`.

Столбец `ID:int` добавляется автоматически в начало каждой таблицы и не задаётся пользователем.

Общие команды:

## CRUD-операции

### Команды

| Команда | Описание |
|---|---|
| `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` | Создать запись |
| `select from <имя_таблицы>` | Прочитать все записи |
| `select from <имя_таблицы> where <столбец> = <значение>` | Прочитать записи по условию |
| `update <имя_таблицы> set <столбец1> = <новое_значение1> where <столбец_условия> = <значение_условия>` | Обновить запись |
| `delete from <имя_таблицы> where <столбец> = <значение>` | Удалить запись |
| `info <имя_таблицы>` | Вывести информацию о таблице |

Правила записи значений:

- строки указываются в кавычках: `"Sergei"`;
- логические значения — `true` / `false`;
- целые числа — без кавычек: `28`;
- значение `ID` не передаётся в `insert`, оно генерируется автоматически;
- все столбцы обязательны, типы значений проверяются по схеме таблицы;
- в `set` можно обновить несколько столбцов через запятую: `set age = 29, is_active = false`.

### Пример использования

```text
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

>>>Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei | 28  |    True   |
+----+--------+-----+-----------+

>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.

>>>Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".

>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Обработка ошибок

- Неизвестная команда: `Функции <имя> нет. Попробуйте снова.`
- Некорректное значение аргумента или неверный тип: `Некорректное значение: <значение>. Попробуйте снова.`
- Обращение к несуществующей таблице: `Ошибка: Таблица "<имя>" не существует.`
- Пустой ввод — приглашение повторяется.

## Хранение данных

Метаданные таблиц хранятся в файле `db_meta.json`, данные каждой таблицы — в файле `data/<имя_таблицы>.json`. Оба пути отсчитываются от директории, из которой запущена программа.

`db_meta.json`:

```json
{
  "users": {
    "columns": [
      ["ID", "int"],
      ["name", "str"],
      ["age", "int"],
      ["is_active", "bool"]
    ]
  }
}
```

`data/users.json`:

```json
[
  {"ID": 1, "name": "Sergei", "age": 28, "is_active": true}
]
```

## Разработка

### Makefile

| Команда | Действие |
|---|---|
| `make install` | Установить зависимости (`uv sync`) |
| `make project` | Запустить программу (`uv run database`) |
| `make build` | Собрать пакет (`uv build`) |
| `make publish` | Проверить метаданные пакета (`uvx twine check dist/*`) |
| `make package-install` | Установить собранный пакет (`uv tool install dist/*.whl`) |
| `make lint` | Проверить код линтером (`uv run ruff check .`) |

### Линтер

Проект использует [Ruff](https://docs.astral.sh/ruff/) для статического анализа и форматирования кода.

```bash
uv run ruff check .
uv run ruff check . --fix
uv run ruff format .
```

## Технологии

- **uv** — управление зависимостями, окружением и сборка пакета.
- **Ruff** — линтер и форматтер.
- **prompt** — ввод данных от пользователя.
- **prettytable** — табличный вывод результатов `select`.
- **shlex** — безопасный разбор командной строки.
- **json** — хранение метаданных и данных таблиц.
